# Changelog

## [0.1.0] - 2026-09-10

Initial release.

- Alert frame showing icon, effect name and countdown for loss of control
- Detection through `C_LossOfControl`; no spell ID table to maintain
- Shows the effect ending last when several overlap, and re-checks on expiry
- Backdrop pulse synchronised to the one-second boundary
- Options window with scale, pulse toggle and per-category filtering
- Frame position and settings persist per account
